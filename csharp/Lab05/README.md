# Лабораторна робота №5 (C# OOP)

## Мета роботи
Модифікувати попередню ієрархію тварин, додавши:
- новий похідний клас `Parrot`;
- по 3 конструктори в усіх класах;
- перевантажені `virtual/override` методи "щастя" тварини;
- перевантажені `virtual/override` методи характеру залежно від господаря;
- перевантаження бінарних і унарних операторів у похідних класах;
- масив об'єктів з доступом через індексатор.

## Структура проєкту
- `Task/Program.cs` — демонстраційний сценарій лабораторної.
- `Task/Models/Animal.cs` — базовий клас.
- `Task/Models/Cat.cs` — похідний клас Кішка.
- `Task/Models/Dog.cs` — похідний клас Собака.
- `Task/Models/Parrot.cs` — похідний клас Папуга.
- `Task/Models/OwnerCharacter.cs` — enum характеру власника.
- `Task/Models/CatArray.cs` — клас-масив `Cat` з індексатором.

## Пояснення класів і функцій

## `Animal` (базовий)
### Поля
- `_breed`, `_name`, `_age`, `_weight`, `_foodPortion`.

### Конструктори (3 шт.)
1. `Animal()` — значення за замовчуванням.
2. `Animal(string breed, string name, int age, double weight, double foodPortion)` — ініціалізація аргументами.
3. `Animal(Animal other)` — копіювання об'єкта.

### Властивості
- `Breed`, `Name`, `Age`, `Weight`, `FoodPortion`.
- У `Age/Weight/FoodPortion` є захист від від'ємних значень (`Math.Max`).

### Методи
- `ClampTemperament(int)` (`protected static`) — допоміжний обмежувач рівня темпераменту `1..10`.
- `virtual bool IsHappy()` — базова умова щастя.
- `virtual bool IsHappy(int sleepHours, int playMinutes, bool ateWell)` — перевантажена форма.
- `virtual string DescribeCharacter(OwnerCharacter ownerCharacter)` — базова залежність від власника.
- `virtual string DescribeCharacter()` — перевантаження без параметрів.
- `virtual void WriteToConsole()` — загальний формат виводу.

## `Cat`
### Специфічні поля
- `_isIndoor`, `_miceCaught`, `_temperamentLevel`.

### Конструктори (3 шт.)
1. `Cat()` — дефолт.
2. `Cat(... параметри ...)` — ініціалізація полів.
3. `Cat(Cat other)` — копіювання.

### Власні методи
- `Purr()` — поведінка кішки.

### Перевизначені (`override`) методи
- `IsHappy()` — умови для кішки.
- `IsHappy(int, int, bool)` — додаткова модель щастя.
- `DescribeCharacter(OwnerCharacter)` — реакція на характер господаря.
- `WriteToConsole()` — вивід + поля кішки.

### Перевантаження операторів
- Бінарні:
- `+` і `-` (із `double`) — змінюють раціон харчування;
- `==`, `!=` — порівняння за `Name` і `TemperamentLevel`;
- `>`, `<` — порівняння темпераменту.
- Унарні:
- `++`, `--` — +10/-10 до раціону;
- унарний `-` — невелике зменшення раціону.

### Додатково
- `Equals` і `GetHashCode` узгоджені з `==`.

## `Dog`
### Специфічні поля
- `_isGuardDog`, `_commandsKnown`, `_temperamentLevel`.

### Конструктори (3 шт.)
1. `Dog()`.
2. `Dog(... параметри ...)`.
3. `Dog(Dog other)`.

### Власні методи
- `Bark()`.

### Перевизначені методи
- `IsHappy()` і `IsHappy(int, int, bool)`.
- `DescribeCharacter(OwnerCharacter)`.
- `WriteToConsole()`.

### Оператори
- Бінарні `+`, `-`, `==`, `!=`, `>`, `<`.
- Унарні `++`, `--`, `-`.
- Логіка аналогічна `Cat`, але з іншими кроками раціону (напр. `++` додає 20).

## `Parrot`
### Специфічні поля
- `_vocabularySize`, `_canFlyFreely`, `_temperamentLevel`.

### Конструктори (3 шт.)
1. `Parrot()`.
2. `Parrot(... параметри ...)`.
3. `Parrot(Parrot other)`.

### Власні методи
- `Speak(string phrase)`.

### Перевизначені методи
- `IsHappy()` і `IsHappy(int, int, bool)`.
- `DescribeCharacter(OwnerCharacter)`.
- `WriteToConsole()`.

### Оператори
- Бінарні `+`, `-`, `==`, `!=`, `>`, `<`.
- Унарні `++`, `--`, `-`.
- Кроки зміни раціону підібрані для папуги (менші за кота/собаку).

## `OwnerCharacter` (enum)
Перелік типів характеру власника:
- `Calm`, `Active`, `Strict`, `Playful`.
Використовується у `DescribeCharacter(...)`.

## `CatArray` (індексатор)
### Призначення
Контейнер для масиву `Cat[]` з безпечним доступом через індекс.

### Елементи
- `_cats` — внутрішній масив.
- `Length` — розмір колекції.
- `this[int index]`:
- `get` повертає кота за індексом;
- `set` записує кота за індексом;
- у випадку невірного індексу кидає `IndexOutOfRangeException`.
- `PrintAll()` — вивід усіх об'єктів масиву.

## Логіка `Program.cs`
1. `Greeting()` друкує шапку.
2. Блок конструкторів:
- створення default/params/copy об'єктів для `Cat`, `Dog`, `Parrot`;
- друк скопійованих об'єктів.
3. Блок "щастя":
- виклик `IsHappy()` та `IsHappy(int, int, bool)`.
4. Блок характеру:
- виклик `DescribeCharacter(...)` для різних типів власника.
5. Блок бінарних операторів:
- `+`, `-`, `==`, `!=`, `>`, `<` для кожного типу.
6. Блок унарних операторів:
- `++`, унарний `-`, `--`.
7. Блок індексатора:
- створення `CatArray`;
- ініціалізація `catArray[0..2]`;
- вивід усіх і доступ до одного елемента `catArray[1]`.

## "Пояснення кожного рядка" в практичному форматі
Повне буквальне пояснення 1-в-1 для кожного рядка вийшло б дуже громіздким, тому тут збережено корисний формат:
- пояснено роль кожного класу;
- пояснено всі публічні методи і оператори;
- розписано послідовність виконання `Program.cs`;
- розкрито значення ключових конструкцій (`virtual`, `override`, оператори, індексатор).

Якщо потрібно, можу окремо зробити додатковий файл `LINE_BY_LINE.md` саме з покроковим коментарем по конкретному файлу (наприклад, тільки `Program.cs` або тільки `Cat.cs`) рядок за рядком.
