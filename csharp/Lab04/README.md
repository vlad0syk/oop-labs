# Лабораторна робота №4 (C# OOP)

## Мета роботи
Показати різні підходи ООП в C# на одній предметній області "Тварини":
- базове наслідування;
- інтерфейсна ієрархія;
- абстрактний базовий клас;
- робота з колекційними інтерфейсами (`IComparable`, `IComparer`, `IEnumerable`).

## Структура проєкту
- `Task/Program.cs` — головний сценарій і демонстрація всіх версій.
- `Task/Models/Animal.cs` — базова сутність тварини + `IComparable<Animal>`.
- `Task/Models/Cat.cs` — клас кішки (версія 1).
- `Task/Models/Dog.cs` — клас собаки (версія 1).
- `Task/Models/IAnimal.cs` — контракт для версії 2.
- `Task/Models/AnimalBase.cs` — базова реалізація для `IAnimal`.
- `Task/Models/CatV2.cs`, `Task/Models/DogV2.cs` — реалізації через інтерфейс.
- `Task/Models/AbstractAnimal.cs` — абстрактна база (версія 3).
- `Task/Models/CatV3.cs`, `Task/Models/DogV3.cs` — реалізації від абстрактного класу.
- `Task/Models/AnimalComparer.cs` — `IComparer<Animal>` (порівняння за зростом).
- `Task/Models/AnimalCollection.cs` — власна колекція з `IEnumerable<Animal>`.

## Логіка `Program.cs` по блоках
1. `Greeting()` друкує шапку лабораторної.
2. `VERSION 1`:
- створюються `Cat` і `Dog`;
- викликаються методи виводу і поведінки;
- демонструються взаємодії між тваринами.
3. `VERSION 2`:
- створюються об'єкти як `IAnimal`;
- показано поліморфізм через інтерфейс;
- для специфічних методів використовується `is` + кастинг.
4. `VERSION 3`:
- створюються `CatV3`, `DogV3` як `AbstractAnimal`;
- викликається абстрактний метод `MakeSound()` через поліморфний масив;
- викликається конкретний метод `Sleep()` з абстрактної бази.
5. `VERSION 4`:
- масив `Animal[]`;
- сортування `Array.Sort(sortedByWeight)` через `IComparable`;
- сортування з `AnimalHeightComparer` через `IComparer`;
- ітерація через власну `AnimalCollection` (`foreach`).

## Пояснення класів і методів

## `Animal`
- Поля: порода, ім'я, характеристики, вага, зріст.
- Конструктори:
- без параметрів — дефолтні значення;
- з параметрами — ініціалізація стану об'єкта.
- Властивості (`Breed`, `Name`, `Characteristics`, `Weight`, `Height`) інкапсулюють поля.
- `WriteToConsole()` (`virtual`) — базовий формат виводу.
- `CompareTo(Animal? other)` — порівнює за вагою для сортування.
- `ToString()` — коротке текстове представлення тварини.

## `Cat` (версія 1)
- Додаткові поля: домашня/вулична, кількість спійманих мишей.
- `WriteToConsole()` (`override`) — додає специфічні поля кішки.
- `Purr()`, `CatchMice(int)`, `Train(string)` — приклади поведінки.
- `Confront(Dog)`, `BeFriendsWith(Dog)` — взаємодія з собакою.

## `Dog` (версія 1)
- Додаткові поля: охоронна собака, список вивчених команд.
- `WriteToConsole()` (`override`) — розширює базовий вивід.
- `Bark()`, `Train(string)`, `Guard()` — поведінка собаки.
- `Confront(Cat)`, `BeFriendsWith(Cat)` — взаємодія з кішкою.

## `IAnimal`
- Визначає контракт:
- загальні властивості тварини;
- методи `WriteToConsole()` і `MakeSound()`.
- Дає можливість працювати з різними класами через спільний інтерфейс.

## `AnimalBase`
- Реалізує `IAnimal` один раз, щоб уникнути дублювання в `CatV2/DogV2`.
- `MakeSound()` повертає базове `"..."`, далі перевизначається в нащадках.

## `CatV2`, `DogV2`
- Демонструють підхід "інтерфейс + спільна база".
- Кожен клас:
- додає своє поле;
- перевизначає `MakeSound()`;
- перевизначає `WriteToConsole()`.

## `AbstractAnimal`
- Спільна логіка і стан для версії 3.
- `abstract string MakeSound()` змушує нащадків реалізувати звук.
- `Sleep()` — готова поведінка, спільна для всіх.

## `CatV3`, `DogV3`
- Наслідують `AbstractAnimal`.
- Реалізують `MakeSound()`.
- Мають специфічні поля/методи:
- `CatV3`: `LivesLeft`, `LoseLife()`;
- `DogV3`: `LoyaltyLevel`, `IncreaseLoyalty()`.

## `AnimalHeightComparer`
- Порівнює тварин за `Height`.
- Якщо зріст однаковий, другий ключ — `Weight`.
- Обробляє `null` коректно.

## `AnimalCollection`
- Обгортка над масивом `Animal[]`.
- Реалізує `IEnumerable<Animal>`, тому працює в `foreach`.
- У `GetEnumerator()` створює копію масиву, сортує, і `yield return` по елементах.
- Має індексатороподібний доступ через `this[int index]`.
- `PrintAll()` виводить колекцію з нумерацією.

## Пояснення ключових конструкцій "по рядках" (суть)
- `namespace Task.Models` — логічне групування типів.
- `private` поля — приховують внутрішній стан.
- `public` властивості — контрольований доступ до полів.
- `virtual`/`override` — поліморфізм.
- `interface` — контракт без конкретної реалізації.
- `abstract class` + `abstract method` — частково готова база + обов'язкова реалізація в нащадках.
- `IComparable<T>` — "природний" порядок сортування.
- `IComparer<T>` — альтернативний порядок.
- `IEnumerable<T>` + `yield return` — кастомний обхід колекції.

## Висновок
У лабораторній №4 один і той самий домен реалізовано різними механізмами ООП. Це дає практичне порівняння підходів і показує, коли зручно використовувати:
- наслідування;
- інтерфейси;
- абстрактні класи;
- колекційні інтерфейси .NET.
